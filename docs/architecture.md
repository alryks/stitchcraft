# Архитектура

```text
Браузер
  │ изображение + параметры / JSON схемы
  ▼
ClojureScript + Reagent :3000
  │ HTTP
  ▼
FastAPI :8000
  ├─ обработка изображений, палитры, участки, материалы, экспорт
  │ HTTP/JSON для каждого связного участка
  ▼
SWI-Prolog :8080
  └─ правила перемещения, выбор метода, отрезки нити, стоимость маршрута
```

Compose создаёт три независимых сервиса. Backend ждёт успешный health check Prolog, frontend — backend. Адрес Prolog берётся из `PROLOG_URL`; браузер получает `PUBLIC_API_URL` через runtime-файл `config.js`.

Backend хранит созданные схемы в памяти. Перезапуск контейнера очищает схемы.

## Модель схемы

Каждая клетка содержит координаты, основной и дополнительный цвет, тип стежка, важность, символ и идентификатор связного участка. Шов назад иголку хранится отдельными отрезками. План региона состоит из метода шитья и одного или нескольких отрезков нити с маршрутом и оценкой длины.
